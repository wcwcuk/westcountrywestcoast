# westcountrywestcoast.com

WCWC Limited's company website, hosted free on GitHub Pages.

All details are filled in. Check them against Companies House before publishing.

Edit freely: it's plain HTML and one CSS file.

Fonts (Bricolage Grotesque, IBM Plex Sans, IBM Plex Mono) are self-hosted in fonts/ under the SIL Open Font License, so the site makes no requests to Google.
The colours follow The Quiet Period: navy #101C28, paper #EDF1F4, mint #5BF0C8 (mint only on navy).
